# תעודות שורש נוספות לבניית האימג' (לא חובה)

רשת עם סינון HTTPS (כמו Netspark) מחליפה את התעודות של האתרים. כדי שבניית האימג' (`docker build`) תעבוד מאחוריה,
שמים כאן את תעודת השורש של הסינון כקובץ `.crt` (PEM) - והאימג' סומך עליה, בלי לכבות אימות תעודות.
קובצי `.crt` לא נכנסים ל-Git. בענן התיקייה ריקה, ושום דבר לא משתנה.

ייצוא מ-Windows (PowerShell): התעודה נמצאת ב-`Cert:\LocalMachine\Root`; את ה-RawData שלה כותבים כ-Base64 בין
`-----BEGIN CERTIFICATE-----` ו-`-----END CERTIFICATE-----`.
